# LiteTerm V0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a lightweight iPadOS terminal app that provides a bounded local file shell and one secure, interactive SSH PTY session with touch-first controls.

**Architecture:** A Foundation-only `LiteTermCore` target contains deterministic shell, path, history, host, trust, and retry policies that can be tested with command-line Swift. The iPad app composes SwiftUI, SwiftTerm, security-scoped file access, Keychain, and SwiftNIO SSH without embedding runtimes or background services.

**Tech Stack:** Swift 6, SwiftUI, UIKit, Security, UniformTypeIdentifiers, SwiftTerm, SwiftNIO SSH, NIOTransportServices, XCTest.

**Spec:** `docs/superpowers/specs/2026-08-24-liteterm-v0.1-design.md`

## Global Constraints

- Deployment target is iPadOS 17.0; the app supports portrait and landscape.
- Local commands are exactly `pwd`, `ls`, `cd`, `cat`, `mkdir`, `touch`, `cp`, `mv`, `rm`, `clear`, and native `edit`.
- Local paths never escape the app container or the currently authorized security-scoped root.
- `cat` and `edit` reject files larger than 5 MiB.
- Terminal type is `xterm-256color`; scrollback is capped at 2,000 lines.
- Shortcut keys are `Esc`, `Ctrl`, `Tab`, `↑`, `↓`, `←`, `→`, `/`; Ctrl is a one-shot latch.
- One SSH session may be active; reconnect has at most 3 attempts delayed by 1, 2, and 4 seconds and runs only in foreground.
- Passwords, private keys, and trusted host fingerprints use Keychain protection `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`.
- V0.1 SSH keys are app-generated Ed25519 keys; arbitrary legacy key import is excluded.
- No VM, bundled language runtime, JIT, local process execution, SFTP, port forwarding, background keepalive, analytics SDK, terminal transcript, or unlimited cache.
- TDD evidence must include the observed failing test before implementation and the passing test afterward.
- No task may delete or overwrite files outside the new `LiteTerm` repository.
