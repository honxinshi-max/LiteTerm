## Current decision

The branch is eligible to be published as a **candidate implementation with named OPEN gates**, not as a completed iPad/App Store release. Static Web has real portable loopback evidence. Python execution remains disabled until the verified XCFramework, Simulator, and physical-iPad gates pass. Swift remains diagnostics/handoff only, and Node/npm remain unsupported.
